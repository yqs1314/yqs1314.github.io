idea推荐的插件

Created2025-05-29

1、推荐插件

easycode是生成代码的，主要是需要自己去配。然后后面就可以自动生成了
key promoter x 是提示快捷键的
maven-search可以直接搜maven依赖的jar包地址一键复制，就不用去官网找了
translation 是翻译的，可以配ai接口然后翻译，对英语不好的人来说帮助非常大。因为源码大部分都是英文的。
smart input pro 这个可以自己切换输入法，就不要自己去切换了。但是现在需要付费
sequenceDiagran 主要是看项目结构的它可以将三层架构怎么调用的用图的方式展示出来
然后免费ai插件的话，个人觉得fittencode比较好用。或者lingma、trae、windsurf。
